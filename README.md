# 🎙️ AI 會議記錄助手

這是一個 AI 輔助的會議工具，能將會議錄音轉換為結構化的會議紀錄（Word 檔）。
專案著重於快速原型開發（vibe coding）與清楚可維護的後端架構。

## ✨ 功能特色
- 上傳會議音訊檔
- AI 自動轉錄與摘要
- 產生結構化的會議紀錄（DOCX）
- 清楚列出待辦事項（負責人與期限）

## 🧠 AI 輔助開發方式（Vibe Coding）
本專案採用 AI 輔助開發流程（vibe coding）：
-採用 Spec（規格驅動開發）
-設計結構化 Prompt（角色 / 格式 / 輸出限制）
-建立 AI 會議紀錄系統（語音 → 文字 → 摘要）
-使用 Gemini 大語言模型 進行摘要整理
-輸出結構化文件
-Cursor 輔助開發，加速原型建立與程式品質迭代
-架構設計、API 規劃與錯誤處理由人主導
-強調快速迭代與長期可維護性

## 底層技術
- 前端：React + Tailwind
- 後端：Java Spring Boot
- AI：Google Gemini
